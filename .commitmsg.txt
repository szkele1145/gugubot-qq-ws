fix(i18n): 绑定系统子命令字改走语言包，清理死键，补 lang 孤儿检查

问题
----
1. bound.py 把管理员子命令的中英双语命令字**硬编码**在源码里：
   if command in ["白名单检查", "whitelist_check"]: ...
   - 语言包里的同名条目成了死键，lang 与代码一旦不同步（改文案/加语言）
     行为就不一致
   - 新增语言必须改 Python 源码
   - lang 键名与命令字拼写不一致（check_extra_bound vs extra_bound_check）
2. en_us.yml 缺 connector.name：4 个连接器用它拼 log_prefix，英文环境下
   每条日志前缀都是 "gugubot.connector.name" 这串 key 本身
3. 23 个死键（两边都有、代码从不引用）

改动
----
- bound.py：管理员子命令一律 self.get_tr(key)，命令字只有语言包一个来源
- lang：check_extra_bound -> extra_bound_check；补 whitelist_check；
  补 en_us 的 connector.name；删除 23 个死键
- tests/test_lang_consistency.py：key 收集扩展到动态形式——括号配对的
  get_tr 实参解析、嵌套 get_tr、变量赋值式、三元赋值式、元组式（含变量
  间接引用）
- tests/test_lang_orphans.py（新增）：反向查死键 + 互查两语言包单边漏译
- tests/test_bound_subcommand_i18n.py（新增）：断言 zh_cn/en_us 的值与旧
  硬编码逐一比对一致（行为不变），且源码不再出现硬编码命令字列表
